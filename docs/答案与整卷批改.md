# 答案记录与批改

在原来的 MathMaster 中使用，题库、扫描导入、笔记与 AI 解题共享本地数据库。

- 单题：打开题目 → **答案与批改**。选择题点击 A/B/C/D，填空题填写结果，解答题填写答案与过程；后两者也可以上传作答图片。点击 **保存答案记录** 或 **核对当前题目**。
- AI 解题面板可以直接选择或填写本题答案，答案同步到原练习记录。点击 **按此答案继续分析**，把自己的选择带入引导；点击 **提交答案 / 图片批改** 打开批改界面。
- AI：用户明确给出最终答案且本轮完成后，自动保存答案、用户表达的过程及委托工具实际计算的步骤。保留已有笔记；历史记录可恢复。
- 整卷：侧栏 **整卷批改** → 选择试卷 → **新建整卷作答**。答案自动保存，可从列表继续历史作答。**整套试卷批改** 会提交全部题目，空白题记零分。
- 选择题按参考选项自动判分；可核验的数学填空直接核对等价性。其他填空、解答与图片作答由当前解题模型自动评分，并显示图片识别结果及得分理由。
- **评分要求 → 编辑评分要求** 可填写说明、依据来源和每个评分点的条件及分值，合计必须等于本题满分。勾选已核对后，AI 严格按这些评分点自动计分：不能超出单项分值，不能漏项或重复项，总分必须与分项得分一致，得分须引用实际作答依据。没有明确细则时标注 **AI 参考估分**，不会作为已核对的最终成绩；总分区域也会显示含估分的成绩。
- 图像或公式不清楚、缺失参考答案、模型判分不满足评分约束时保持待评分，作答仍然保存。可重试或 **人工评分 / 修正**。
- 修改作答后旧成绩保留并提示重新批改。人工评分保留原评分记录。整卷支持导出答案与成绩 JSON。

每题最多五张 PNG、JPEG、WebP 作答图片，单张最多 10 MB。图片单独保存在 `data/uploads/answer-images`，不会替换原题图；移除当前图片不会删除已提交记录中的图片。单题图片草稿和整卷图片答案都可继续作答。整卷按新建时的题目、答案与评分要求快照批改；评分要求改变后，新建整卷使用新要求；已保存的整卷也可以点击「复制作答并更新评分要求」，原答案和旧成绩仍保留。2026 数学试卷缺失的分值已从保存的来源页面补齐，两套均为 150 分，解析与向量直接复用。

记录保存在 `data/mathmaster.db`，原来的“下载完整本地备份”包含新增记录与作答图片。模型批改复用现有 `data/ai-cache.db`，相同有效请求可直接命中本地缓存。选择题和真正未作答的题不调用模型；只上传图片也算作答。

## 408 试卷

本机已导入 2009—2026 年 18 套全国统考 408 真题，共 846 题；每套 40 道选择题、7 道综合应用题，150 分。资料来自[四〇八档案室](https://zhenti.beokayy.club/)，是公开整理的统考真题，不是教育部发布的原始扫描件或官方评分细则。参考答案按整理来源使用，题图/公式保留核对提示。

完整题干、选项及参考答案均入库。145 道含配图题保存了完整题干的本地题图，每年另有排版生成的完整试卷 PDF。页面的“打开原始试卷”在这些导入试卷中打开本地整理 PDF。

来源页面快照、链接、采集时间、内容摘要保存在 `data/sources/408`。试卷与题图保存在 `data/uploads/real-408-年份`。

再次导入可运行 `scripts/import_408.py`：先 `prepare` 下载与检查公开页面，使用安装有 Playwright 的开发 Python 执行 `scripts/render_408.py`，再 `install` 入库。已有同 ID 完整试卷保持原样，不覆盖练习记录。工具只用于本地学习资料整理，不上传 GitHub。
