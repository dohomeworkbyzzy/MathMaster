# 试卷预解析与本地知识库

AI 解题的“本地缓存”面板显示长期预解析库的题目数与后台进度。该库保存在原软件 `data/mathmaster.db` 的 `question_knowledge` 表，原来的完整本地备份包含它。

预解析保存题干识别结果、题目结构、知识点、候选方法、首步问题、关键条件、参考解析与评分依据。已有公开解析优先复用；数学题图由已配置的 DeepSeek V4.1 Flash 批量识别。参考解析采用题库与来源页面，未核对的 AI 推导不作为评分标准。

每题按题干、题图内容、参考答案、分值与解析版本匹配。修改题目或参考答案后不会继续使用旧解析。OCR 文本仍需对照图片确认；精确确认已缓存的 OCR 后，解析随新题干版本复用，保留题型和分值。手工改成另一题则重新解析。

运行时优先读取本地 OCR 和题目结构，省去重复图片识别和题型分析调用；批改复用已识别题干、参考资料与评分依据。确定是纯文字公式的清晰题图无需再次发送给模型。带图形或不确定的题目继续保留题图核对。

学生尚未解出时只向老师提供知识点和候选方法名称，不提前提供完整解。明确要求完整讲解或完成首解后才提供缓存参考解析进行复习与其他方法教学。新的解题描述、个性化引导和主观题评分仍需要模型。

临时响应缓存 `data/ai-cache.db` 与长期知识库分开。清空临时缓存不会删除题目预解析，也不会删除题库、笔记或成绩。模型与工具的运行结果继续使用原有响应缓存。

开发时可执行 `scripts/preanalyse_papers.py`，已经存储且题目版本相同的解析会复用，失败题会重新尝试。Windows 运行本机 Python 并加 `-X utf8`，例如：

```text
.venv-win\Scripts\python.exe -X utf8 scripts\preanalyse_papers.py --workers 3 --batch-size 3
```

数学参考页面快照存放在 `data/sources/math`；408 补充解析快照存放在 `data/sources/408/analysis-sources`。来源是公开整理页面，不是官方评分细则。
