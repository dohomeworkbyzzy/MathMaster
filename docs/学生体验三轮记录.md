# 学生体验与改进记录

日期：2026-10-27。以学生身份体验现有 MathMaster 题库；使用真实题库的数据库副本及本地浏览器，练习记录写入隔离副本。实际体验与自动回归均不代表真实学生、真实手机或公网服务的验收。

每轮范围：进入首页 → 选科目或查找题目 → 阅读题目 → 作答及记录思路 → 核对或查看结果 → 标记、继续下一题或复习 → 返回并验证记录。每轮结束后集中整理问题、修改和复测。AI 服务与图片上传需实际配置和设备，未假装已经验收。

## 第一轮：桌面端 408 选择题

- 流程：1366×768，在现有王道操作系统题库搜索并打开第 1 题；阅读题图，选择 C、记录笔记、完成并加入错题本；发起核对，进入下一题；打开错题本并返回，从首页继续上一道题，确认答案与笔记保留。
- 发现：搜索没有结果时误称题库为空，也没有清除筛选；OCR 把同一行多个选项合并在 A；答题入口排在笔记下方；错题复习返回普通题库；常见屏幕高度下选项需额外滚动；题目“待检查”状态覆盖作答进度。
- 改进：按筛选条件显示无结果提示并允许一键清除；只在完整 A–D 顺序明确时拆分同行选项；将答案放在笔记之前；从错题本进入的练习返回错题本；练习侧栏选择题采用两列；卡片同时展示待检查和作答状态。
- 核对界面曾先出现“等待批改”，需等待最终状态；不能把等待状态当作最终评分。下轮继续检查。

## 第二轮：桌面端数学真题与计算

- 流程：1024×768，按数学二、2012 年真题筛选；阅读题图，选择 C 并记录思路，运行本地计算器，完成和标记错题；等待核对完成，显示 4/4；继续下一题，回错题本及首页恢复作答。
- 发现：切换题库、错题本或筛选条件时，旧列表会在新请求的短暂间隔内继续显示，快速点击可能打开旧结果；1024 像素宽时题目标题栏过窄，文字被挤成竖排。
- 改进：切换或更改筛选立即显示读取状态，废弃过期请求，直到新结果返回才展示列表；题目标题栏在空间不足时换行，避免竖排；加入延迟响应的浏览器回归场景。

## 第三轮：小窗口填空与复习

- 流程：620×600，选择数学二 2012 真题第 9 题，阅读题图、填写示例答案与思路、查看参考、完成并标记错题；进入下一题后，通过题库返回错题本，重新打开并从首页续做，答案和笔记均保留；页面无横向溢出。
- 发现：小窗口练习中侧栏隐藏，不能直接进入错题本，必须先返回题库；本题未录入参考答案，界面明确提示缺失，不能据此声称答案正确。
- 改进：小窗口练习工具栏增加“打开错题本”，复习时仍可直接返回错题本；跳转前沿用现有保存流程。
