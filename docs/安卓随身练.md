# MathMaster 随身练（安卓 0.1.1）

用途：手机展示电脑网站中的题目，纸上作答后上传文字、笔记与照片，继续 AI 解题并推荐下一题。手机页面不包含电子草稿、触控板或桌面计算器。

## 安装和连接

安装 `artifacts/MathMaster-Mobile-0.1.1-debug.apk`。这是可直接安装的调试签名测试包，支持 Android 8.0 及以上，Android System WebView / Chrome 需为 111 及以上版本。

首次打开点“设置 → 网站服务器 → 添加 IP、端口或域名”，填入网站根地址，再点“测试并连接”。支持：

- `http://192.168.1.10:8765`：电脑 IP 和端口。
- `https://math.example.com`：域名。
- `https://math.example.com:8443`：域名和自定义端口。

省略协议时按 HTTP 连接。HTTPS 地址请明确写 `https://`。输入末尾 `/mobile` 会自动转为根地址。连接时检查 `/api/health` 和 `/mobile`，测试通过才切换；HTTP 403、404 和连接超时会给出原因。

App 页面底部“设置 → 管理服务器地址”可保存、编辑、测试、切换、删除多个地址；顶部不再显示服务器地址或服务器工具栏。连接失败时通过提示页“设置 → 网站服务器”修改地址。IP 或端口变化后编辑即可，无需重新安装。切换前先上传做题记录；不同域名的手机暂存内容独立保存，即使两个地址实际指向同一台服务器也是如此。

## 手机做题

1. 在题库中搜索题目，按科目或试卷筛选，打开题目。题图保持原比例并可打开原图预览、双指缩放。
2. 在纸上作答，在“作答与上传”填写答案、笔记和进度；可标记错题。
3. “上传纸上作答照片”从系统选择器选择已经拍好的照片，支持多选，每题最多五张，每张最多 10 MB，支持 PNG / JPEG / WebP。App 不直接调用相机，可先用手机相机拍照再选取。
4. 点“上传做题记录”，将文字和照片引用保存成网站的历史作答记录；打开“记录”可继续最近二十道题，题目内可查看最近五十条历史提交。
5. 文字修改会暂存手机，返回题库或切换页签时同步当前网站。上传照片后会立即保存其当前附件列表；历史提交中的照片不会因为移除当前附件而被删除。
6. 手机、电脑同时修改同一题时拒绝覆盖。点击“保留手机副本，读取网站最新记录”，可以查看旧手机文字副本并手动填回、合并后再次上传。电脑端已有草稿会保留。

## AI 解题、下一题和 API 切换

“AI 解题 / 推荐”复用网站 AI 会话，可描述思路、请求当前步骤计算、查看公式和回复；对扫描题可先“识别题图 / 核对题干”，确认后使用。未确认的消息会保留请求编号，可“核对 / 重试未确认消息”，避免重复提交。

“推荐下一题”复用网站的知识点与练习记录推荐逻辑，先展示理由，再点“开始推荐题”。向量库未就绪时网站可能调用当前 AI 模型推荐；没有可用模型或网络失败会明确报错。

“设置”中的 API 配置可新增、编辑、测试、启用不同解题模型或向量模型。配置写入当前网站后端，会影响该网站电脑端之后的 AI 请求；密钥保存在服务器而非 APK 内。

## 网站必须在线

App 加载的是当前网站 `/mobile` 页面及同源 API，题库和历史记录与电脑网站共用。App 没有离线题库或本地 AI：电脑屏幕可关闭，但如果后端部署在电脑上，电脑不能关机或休眠；外网使用需要可从手机访问的域名 / 服务。

网站端需使用本项目新版源码并执行 `npm run build`，重启后端使 `/mobile` 生效。网页也可以直接访问 `网站根地址/mobile`。

已有反向代理可以继续使用原域名，无需更改 App。局域网 IP 直连时后端必须监听可访问的网卡地址，且显式允许该访问来源，例如设置 `MATHMASTER_ALLOWED_ORIGINS=http://192.168.1.10:8765`。既有 `data/network-access.json` 的 `allowed_origins` 也继续有效。防火墙需允许对应端口；不要直接取消来源检查。网站仍是原来的单用户服务。

## 构建与验证

前端：`npm run build`。安卓：Java 17、Android SDK 35，在 `android` 目录配置 `local.properties` 后运行 `gradlew.bat assembleDebug lintDebug`。Windows SDK 路径示例 `sdk.dir=D\:\\sdk`，Java 版本应显式选 17，避免系统 Java 8。

相关源码：`web/mobile/`、`android/`，手机入口路由在 `backend/app.py`。Android WebView 文件选择依据 [WebChromeClient 官方接口](https://developer.android.com/reference/android/webkit/WebChromeClient)，页面导航依据 [WebView 官方说明](https://developer.android.com/develop/ui/views/layout/webapps/webview)。

自动验收包含手机尺寸浏览器流程、作答照片真实上传与重开恢复、桌面草稿保留、并发修改及副本恢复、API 配置保存启用，以及模拟 AI 回复和推荐跳转。模拟接口流程不等于本次已验证真实付费模型返回，实际手机网络与照片选择仍需安装后验收。

本次验收（2026-10-15）：前端构建通过；手机页面 2 项流程、原有 API 配置 4 项及继续练习 2 项浏览器回归通过；后端来源限制、练习和作答照片相关 11 项测试通过。APK `assembleDebug`、`lintDebug` 和签名验证通过（lint 无错误）。安卓模拟器完成安装启动、域名连接、IP＋端口连接、两套地址保存和重启恢复；模拟器内置 WebView 74，已验证明确显示更新提示，未把它计作完整网页运行验收。当前网站 `/mobile` 经外部域名确认返回 200。实体手机和真实 AI 服务本次未验收。
