# 原题库中的 AI 解题

1. 启动这个目录的 MathMaster，进入「本地题库」，打开题目，点「AI 解题」。AI 模式收起草稿区，只显示题目和对话；关闭 AI 后恢复原草稿和笔记。
2. 图片题会读取当前裁剪题图。对照左侧原图核对公式，点「确认并保存到题库」。这仍然是原来的同一道题。
3. 输入思路，例如「我想用泰勒法，先比较分子分母」。老师只推动一个关键步骤。
4. 需要代算时说「分子一次项抵消了，帮我展开到二阶，保留余项」。实际计算结果进入本题计算记录，点「写入本题笔记」可放入原笔记。
5. 说出自己的结论。首解完成后点「练另一解法」，继续对原题逐步练习；点「推荐下一题」从同科目的原题库选题；未核对的题先识别、确认。

右上角齿轮设置兼容 Chat Completions 的国产模型或中转接口。地址填到 `/v1`（供应商支持不带 `/v1` 时按其地址填写），模型名称使用供应商实际支持的名称。DeepSeek V4.1 Flash 的官方 API 名称填写 `deepseek-flash`，页面显示完整型号。题图识别需要支持图片输入的模型。已配置的本机 math-408-agent 模型可直接复用。

扫描和裁题继续使用原软件「导入试卷 → 检查 / 编辑」，科目支持数学一、二、三和 408。题目、草稿、笔记、AI 对话、代算记录保存在原 `data/mathmaster.db`，原备份功能一并保存。API 密钥位于本机用户配置目录，不写入题库备份。

委托代算不记成知识薄弱。学习记录只引用你本轮说出的判断，未核对题目和已看答案后的判断不计入薄弱项；两道不同题均出现明确错误才标为「需要巩固」。可在「学习记录」中撤销判断。不能独立核验的最终结论会明确标为待核对。

对话下方的状态条显示当前处理阶段、等待秒数，以及回复是否完成保存。暂时断线会自动核对后台记录，也可点「刷新结果」。出现「发送结果待确认」时不要重新抄一遍输入，点「核对并重试发送」；它沿用本次请求编号，后台已接收时不会再次调用模型。明确失败后，输入仍保留，可点失败消息旁的「重试」重新处理。`zx`、`zy`、`z_x`、`z_y` 可作为解方程的偏导未知量，带参数方程会在结果旁列出适用条件。

## 本地缓存与用量

缓存默认开启，保存在原数据目录 `data/ai-cache.db`。题图识别、题目结构解析、完全相同的模型请求与计算工具结果可复用；同一请求同时打开两次时只发起一次模型调用。模型、账户、请求内容、题图或计算参数变化会重新处理，模型报错及格式无效的回复不入缓存。题图/题目解析保留 30 天，对话结果 7 天，计算结果 180 天；总结果容量上限 64 MB、5000 条，自动淘汰过期和较久未使用的条目。

完整题目对话和推导仍在 `mathmaster.db`。每轮发送最近 6 轮对话、有限的早期摘录和当前有效计算结果，去除重复推导内容；摘要不作为适用条件已成立的证明。固定工具说明和题干位于稳定消息前缀，方便 DeepSeek 自动匹配服务端上下文缓存，实际命中量以接口返回为准。

点击 AI 面板的「本地缓存」，查看累计复用次数、减少发送的输入 tokens、服务端缓存命中 tokens 和占用空间，也可清空缓存。清空不删除题库、笔记、草稿、AI 对话或学习记录，统计保留累计值。缓存只保存请求摘要哈希和成功结果，不保存原始请求或 API 密钥；原备份包含完整学习记录，缓存可重新生成。

本地命中时不再调用模型。新的对话步骤仍需调用 API，服务端缓存也按供应商规则计费。服务端机制见 [DeepSeek 官方缓存说明](https://api-docs.deepseek.com/zh-cn/guides/kv_cache/)。
