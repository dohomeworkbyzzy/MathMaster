# 访问者触摸板与 AI 草稿

AI 解题模式下，左侧上方显示题目，下方为电子草稿，右侧保留 AI 对话。电子草稿与普通练习模式共享当前题目的同一份笔迹，按当前用户自动保存。草稿不会自动作为图片发送给 AI。

## 访问者电脑

1. 点击“触控板书写”，在连接窗口下载 Windows 触控板助手。
2. 解压后双击 `MathMasterTouchpad.exe`，不需要安装 Python。
3. 连接外接鼠标，保持助手窗口开启，将窗口中的八位配对码填入网页。
4. 连接时会弹出本机助手连接窗口，允许弹出窗口并保持它开启，然后返回题目页面。该窗口在本机读取硬件，再将笔迹传给当前页面，公网 HTTP 页面无需直接跨域请求本机。
5. 用外接鼠标移到草稿上选择落笔位置，再用触摸板书写；移动外接鼠标收笔并换位置。
6. 点击“完成”或按 Esc 结束当前书写；关闭助手窗口或 Ctrl+C 可退出助手。

需要 Windows 和支持绝对坐标的 Precision Touchpad。普通鼠标拖动、触屏和手写笔仍可直接在画布上书写。

本地打开 MathMaster 时仍可直接使用原有本机采集。通过域名或其他电脑地址访问时，网页通过本机连接窗口接入访问者的 `127.0.0.1:18765` 助手，不调用服务器触摸板。助手只监听本机回环地址，通过配对码、网页来源和会话令牌绑定连接；配对码不保存到服务器。

## 构建与部署

在 Windows 构建环境中执行：

```bat
.venv-win\Scripts\python.exe scripts\package_touchpad_helper.py
npm run build
```

前一命令生成 `public/assets/MathMasterTouchpad.zip`，后者将其复制到 `dist/assets/MathMasterTouchpad.zip`。部署时更新完整 `dist`，通过现有 `/assets/MathMasterTouchpad.zip` 静态资源路径提供下载；已有 Windows 服务器只需替换 `_internal/dist`。生成的二进制不纳入 Git。

自动测试覆盖配对码校验、来源隔离、会话流、停止连接、远程页面选择本地助手、AI 草稿保存与切换。模拟流不代表真实触摸板手感验收；实际设备支持和公网域名下浏览器授权仍需在访问者电脑确认。
