# MathMaster 使用手册

MathMaster 适合在没有纸笔的情况下练习考研数学。题目、草稿、笔记和计算器可以同时使用，所有常用运算与学习记录都在本机完成。

## 1. 下载和启动

### Windows 安装版（推荐）

从 [Releases](https://github.com/dohomeworkbyzzy/MathMaster/releases) 下载 `MathMaster-Setup-0.2.0-x64.exe`，双击安装后从桌面或开始菜单启动。安装版自带 Python、SymPy 和前端，无需另装 Python / Node.js，首次启动也不需要联网安装依赖。

适用 Windows 10/11 x64。后台服务可从通知区域的 MathMaster 托盘菜单退出；仅关闭界面时服务继续运行。题库位于 `%LOCALAPPDATA%\MathMaster\data`，升级和卸载保留数据。完整安装、迁移、校验和打包方式见 [Windows 安装版](Windows安装版.md)。

### Windows 源码 / ZIP

1. 安装 [Python](https://www.python.org/downloads/) 3.11 或更新版本，建议 3.13；安装时勾选 **Add Python to PATH**。
2. 安装 [Node.js](https://nodejs.org/) 22.12 或更新版本，建议使用当前 LTS。源码首次构建需要 Node.js；已包含 `dist` 的运行包可跳过这一步。
3. 从 GitHub 的 **Code → Download ZIP** 下载并完整解压，或使用 Git 克隆。不要直接在 ZIP 内运行。
4. 双击根目录 `start.bat`。首次启动会创建 `.venv-win`、安装 Python 依赖、构建前端，然后打开独立窗口。
5. 保持启动控制台运行。关闭应用窗口仅关闭界面；关闭启动控制台或按 Ctrl+C 才会停止服务。

日常启动仍然双击 `start.bat`，不需要重复安装。首次安装依赖需要联网；准备完成后，计算、导入本地文件、做题和保存可离线使用。地址为 `http://127.0.0.1:8765`。

已有 Node.js 但启动提示找不到 `npm` 时，重新打开命令提示符或重启电脑，让 PATH 生效。启动失败时保留错误信息，检查 Python、Node.js 版本和依赖下载是否成功。

### Linux / WSL

安装 Python 3.11+、Node.js 22.12+ 和 Python venv 支持，然后执行：

```bash
bash start.sh
```

Windows 和 WSL 使用各自的虚拟环境和原生 npm 依赖。不要同时用两个系统向同一个 `node_modules` 安装依赖，也不要同时运行两个服务操作同一个数据库。原始触控板输入与系统窗口控制仅支持 Windows；其他系统仍可使用计算器、题库和鼠标草稿。

## 2. 第一次体验

### 小窗口做题

点击顶部「小窗」，或把窗口缩到较小宽度/高度。v0.3.0 会优先显示题目和电子草稿，默认收起计算器及笔记/答案。点「笔记与答案」或「展开计算器」可临时打开；收起或还原窗口后输入内容保留。长题在题目区内滚动阅读，拖动题目与草稿之间的分隔线可调整空间。

原版的书写背景跟随系统深浅色，选择皮肤时使用该皮肤配色。已保存的笔画会重新按当前配色显示，原始题图不做颜色反转或内容修改。

手机配套功能见 [手机黑屏草稿使用说明](手机黑屏草稿使用说明.md)：TouchDeck 的黑屏盲操是纯黑画面加最低窗口亮度，实际系统息屏/锁屏后不能据此宣称继续接收手写触摸。

新安装的题库为空，自己的题目和计算记录从首次使用开始建立。

1. 在「计算工作台」选择「积分」。
2. 切换到「文本表达式」，输入 `x*exp(x)`，变量选 `x`。
3. 点击计算，选择「完整步骤」，查看分部积分与结果验证。
4. 打开「本地题库」，新建题目，填写题号与题干，例如「计算 $\int x e^x dx$」。
5. 开始练习，使用草稿与笔记；在右侧计算器重算，并点击「插入解题笔记」。
6. 返回题库，再次打开本题，确认笔记、笔迹与计算推导已保留。

## 3. 积分

公式输入使用 MathLive，可用分数、根号、三角函数快捷键和数学虚拟键盘；也可切换到文本表达式。

| 目的 | 被积函数 | 下限 / 上限 | 预期结果 |
| --- | --- | --- | --- |
| 分部积分 | `x*exp(x)` | 不定积分 | `(x-1)*exp(x)+C` |
| 换元积分 | `2x/(x^2+1)` | 不定积分 | `log(x^2+1)+C` |
| 反正切 | `1/(1+x^2)` | 不定积分 | `atan(x)+C` |
| 定积分 | `x^2` | `0` / `1` | `1/3` |
| 简单反常积分 | `1/sqrt(x)` | `0` / `1` | `2` |

不定积分会显示常数 `C`。填写被积函数即可，不要把完整积分号和上下限一起粘到函数框。定积分或反常积分选择对应模式，并分别填写上下限；无穷使用 `oo`、负无穷使用 `-oo`。

三种展示方式：只看答案、完整步骤、逐步提示。可以复制结果或 LaTeX；做题时可以插入当前题目的笔记。

**验证通过与推导完整是两件事。** 如果引擎只得到答案而没有适配详细推导，界面会说明缺少步骤。看到定义域、奇点、收敛或参数条件时，应连同条件使用结果；不能把未验证或发散的提示当成普通答案。

## 4. 求导

选择「求导」，填写函数、变量和阶数。支持 1–8 阶，以及指定变量序列的混合偏导。

- `sin(x^2)`、变量 `x`、一阶：结果 `2x*cos(x^2)`，展示链式法则。
- `x^5`、变量 `x`、三阶：结果 `60x^2`。
- `x^2*y^3`、混合偏导填写 `x,y`：依次对 `x`、`y` 求导，得到 `6x*y^2`。

其他变量视为独立实变量。当前没有隐函数求导入口。

## 5. 矩阵与行列式

在表格内逐项输入，可增加或删除行列，也可从 Excel 复制矩形区域后粘贴。分数请写 `1/2`，不要先转换成小数。

矩阵支持加、减、乘、转置、逆矩阵、秩、行最简形和线性方程组；需要第二矩阵时填写矩阵 B，解方程时 B 是右端向量。矩阵最多 8×8，按行展开的行列式最多 5 阶。

可先输入：

```text
1  2
3  4
```

其行列式为 `-2`，逆矩阵为：

```text
-2    1
3/2  -1/2
```

初等变换步骤显示交换、倍乘、倍加的行号、系数、前后矩阵及行列式影响。求逆使用 `[A|I]` 的增广矩阵。奇异矩阵会明确提示不能求逆。

含符号参数时，消元步骤可能只适用于列出的非零主元条件；特殊参数需要代入重算，当前不自动穷举全部参数分支。

## 6. 导入和校对试卷

在「导入试卷」选择数学一、二或三，填写试卷名并上传 PDF、扫描 PDF 或 DOCX。单次文件最多 30 MB、PDF 最多 80 页。

导入后会生成候选题目，全部需要检查。打开题目编辑界面，对照原始截图核对题号、题干和参考答案，再标记确认。必要时调整、合并题目、按光标位置拆分文字或裁切截图。复杂双栏、重复小题编号、页眉和跨页布局可能需要手动处理。

### 扫描 PDF

本地 OCR 使用 [Tesseract](https://github.com/tesseract-ocr/tesseract)，建议安装 `chi_sim` 和 `eng` 语言包。Windows 安装说明见 [Tesseract 官方文档](https://tesseract-ocr.github.io/tessdoc/Installation.html)。找不到程序时可在启动前设置：

```bat
set TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe
start.bat
```

没有 OCR 工具时依然保留扫描截图供人工校对。OCR 不可靠地识别数学公式，原图是核对依据；选中文字发送到计算器前必须确认表达式。

### DOCX

安装 [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/) 后，可先转成 PDF 并保留版式截图。未安装时仅提取段落、表格和内嵌图片，保留原 DOCX；Office 数学公式不能直接当可信表达式，建议将文件另存为 PDF 后导入。

## 7. 做题布局

题目在上，草稿与笔记在下，计算器在右。题目图片完整等比例显示；自动调节按题目实际高度分配空间，长题会压缩草稿，超过一屏时整页可滚动。

- 拖动题目与草稿之间的横线，手动调节高度。
- 双击横线或开启「自动调节」，恢复自动分配。
- 收起侧栏或计算器，可扩大题目和草稿范围。
- 计算器可展开、收起、浮动或全屏；拖动分隔线调节宽度。
- 解题笔记支持 `$LaTeX$` 和 `$$LaTeX$$`，可预览、导出 Markdown。

计算推导插入后保存完整结构化记录，重新打开仍能展示公式、中文步骤、验证状态与条件。每题的计算历史独立；题目外的计算保存为独立计算历史。

## 8. 草稿和触控板书写

普通鼠标或触控笔：按住拖动书写，工具栏提供撤销和清空。

原始触控板书写要求 **Windows 精密触控板（Precision Touchpad）和外接鼠标**：

1. 用 Windows `start.bat` 启动，打开一道题，点击「触控板书写」。
2. 外接鼠标在草稿中选择落笔中心。
3. 手指接触触控板直接落笔，整块触控板映射到放大的书写区；抬指结束当前笔画，不需要按住触控板按钮。
4. 用外接鼠标移动，当前一组笔迹会缩小到刚才的草稿位置，下一组按新的位置书写。
5. 「书写区」滑块调整预览宽度，默认 420px，可选 200–1000px，受当前窗口边界限制；这个设置会记住。
6. 「收笔」的小、中、大调整保存后的字迹大小，与预览宽度独立。
7. Esc 或「完成」收笔退出；切换窗口、连接断开也会收笔。

触控板接触期间固定系统光标；抬指、检测到外接鼠标操作、失焦或退出时解除。外接鼠标在本次手指接触结束前拥有优先权。原始输入进程会随会话结束关闭。

旧式只上报鼠标移动的触控板无法提供绝对坐标，界面会说明不支持。不同厂商报告、显示缩放和鼠标同时操作的手感仍需在你的设备上试用。系统多指手势没有全部接管。

**手写内容是电子草稿，不会自动转成公式或计算答案。** 正式运算仍使用计算器的公式输入框。

## 9. 小窗口

Windows 优先使用 Edge/Chrome 独立应用窗口打开，可拖动标题栏移动、拉伸边缘改大小、从任务栏恢复。

右上角「小窗」收缩为 640×520 并收起侧栏；「还原」恢复之前大小；「—」最小化。没有安装 Edge/Chrome 时回退到普通浏览器。窗口控制仅操作当前前台的 MathMaster 浏览器窗口，其他应用不会被调整。

### 界面皮肤与快速切换

右上角「切换皮肤」提供原版、VS Code、Word 文档和 Excel 表格四种风格。选择自动保存在当前浏览器，下次启动继续使用。皮肤适用于计算、题库和做题工作台，切换时保留当前输入、笔记和草稿。

- **VS Code**：深色编辑器、文件导航、编辑器标签和底部状态栏。
- **Word 文档**：蓝色标题栏、功能区、标尺与白纸布局。
- **Excel 表格**：绿色标题栏、功能区、公式栏、网格背景与工作表状态栏。
- **F8**：立即显示独立的工作报告，再按 F8 或点击「返回工作区」恢复当前页面；输入框、全屏计算器中也可使用。小窗下可从皮肤菜单进入。部分笔记本需要 Fn+F8。

工作报告是展示用模板，功能区和状态栏用于模拟外观，不提供 Word / Excel 文件编辑。报告显示期间当前题目继续自动保存；触控板书写会收笔退出。网页标题也会随皮肤切换，浏览器地址、本地服务与 Windows 托盘名称仍保留原信息。

## 10. 保存、错题与参考答案

答案、笔记和已收笔的草稿自动保存。离开题目前会等待同步；失败时保留当前页面及浏览器草稿。计算结果产生后自动写入历史，不需要手动保存。

「完成本题」记录作答状态，「加入错题本」标记需要复习的题。参考答案需要自己填写或从有授权的资料录入，系统不会凭空生成官方答案。

同一题不要在多个窗口同时修改。发生版本冲突时，系统保留旧草稿供下载或手动恢复，不自动覆盖新记录。

## 11. 备份、迁移和更新

在「使用说明 → 下载完整本地备份」保存 ZIP，包含 SQLite 数据库与原始试卷/截图。笔记 Markdown 导出不包含全部题库和手写笔画，不能替代完整备份。

迁移到另一台电脑：先安装并启动新程序，停止服务，备份目标数据目录，再将 ZIP 中的 `mathmaster.db` 和 `uploads` 放入其中。源码 / ZIP 版使用项目的 `data`；安装版使用 `%LOCALAPPDATA%\MathMaster\data`，可从托盘打开。不要在服务运行时替换数据库；旧的 `mathmaster.db-wal`、`mathmaster.db-shm` 不要跟新数据库混用。

更新源码前先备份。Git 用户可以 `git pull` 后重新启动；下载 ZIP 的用户把自己的 `data` 放到新版本目录再启动。不要删除旧目录或数据库后才想起备份。

安装版更新：备份、托盘退出，然后运行新版安装 EXE。无需移动数据；卸载也保留个人记录。源码版到安装版的题库迁移需按上述备份恢复流程完成。

## 12. 可选公开真题导入

仓库不包含作者的个人题库、作答、试卷文件或第三方题图。正常使用可直接导入自己已有的试卷。

另提供公开来源导入脚本，固定来源版本并校验文件摘要；它下载到本机，需要联网、第三方来源仍可访问以及自行确认资料使用条件：

```bat
.venv-win\Scripts\python.exe scripts\import_real_exams.py
```

Linux / WSL 使用 `.venv/bin/python scripts/import_real_exams.py`。当前脚本覆盖 2012–2026 年数学一、二的来源布局；这是固定数据集，并非保证未来年份自动更新的通用爬虫。脚本使用幂等插入，不覆盖已有作答，重复执行仍需核对下载来源与题图。

## 13. 常见问题

| 情况 | 处理 |
| --- | --- |
| 首次启动安装失败 | 检查 Python/Node.js 版本、PATH、联网和依赖源；保留启动窗口报错 |
| 浏览器打不开 | 检查控制台是否仍运行，手动打开 `http://127.0.0.1:8765` |
| 扫描页没有文字 | 检查本地 Tesseract 和语言包，或直接按截图人工拆题 |
| DOCX 没有原版式 | 安装 LibreOffice，或将文档另存 PDF |
| 积分没有完整步骤 | 当前规则未覆盖；查看结果验证与提示，不能把缺步骤当完整推导 |
| 计算超时 | 简化表达式、减小矩阵；超时工作进程会被终止 |
| 触控板无法开启 | 确认 Windows 启动、精密触控板和外接鼠标，旧式鼠标型触控板不支持 |
| 光标暂时被固定 | 抬指或移动外接鼠标，按 Esc 退出；切换窗口也会解除 |
| 保存出现冲突 | 保留提示中的本机草稿，停止多窗口同时编辑后手动处理 |

报告问题时提供操作步骤、系统/浏览器版本和错误提示即可。不要把自己的数据库、完整备份或私人试卷上传到公开 Issue。
