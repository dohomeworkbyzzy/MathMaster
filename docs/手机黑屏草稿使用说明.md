# TouchDeck 手机黑屏草稿

MathMaster 0.3.0 可以把 Android 手机的整个触摸区域映射到电脑草稿中的落笔框。配套软件是 TouchDeck 0.2.2，支持普通显示、黑屏盲操和横竖屏切换。

## 下载与安装

从 [MathMaster v0.3.0 Releases](https://github.com/dohomeworkbyzzy/MathMaster/releases/tag/v0.3.0) 下载电脑安装包 `MathMaster-Setup-0.3.0-x64.exe` 和手机测试版 `TouchDeck-v0.2.2-debug.apk`。APK 约 57 MB，要求 Android 9 或更新版本。随附 SHA256 文件以及 `TouchDeck-0.2.2-notices.zip`。

将 APK 传到手机，从文件管理器打开并允许该文件管理器“安装未知应用”。这是 Debug 签名的测试版。如果已有 TouchDeck 使用另一签名而不能覆盖安装，先用应用的导出功能备份自定义布局，再处理旧版本；卸载可能删除其设置。

开发者也可以用 `adb install -r TouchDeck-v0.2.2-debug.apk` 安装；普通使用无需 USB 调试，也不需要 root。

## 连接并书写

1. 电脑与手机连接同一可信局域网。电脑启动 MathMaster，进入题目的电子草稿，点 **手机书写**。
2. 页面显示电脑 IP、端口与本次 6 位配对码。在手机 TouchDeck 的 **连接 → MathMaster 手机草稿** 填入 IP 和配对码，点 **连接并书写**。
3. 将外接鼠标移到电脑草稿上，确认 **落笔范围** 框。手机的整个书写区对应这个框，并保持宽高比。
4. 在手机上用单指书写。默认选择“草稿整宽”；也可以缩小落笔范围。范围受电脑可见草稿区的高度限制，可拖动题目与草稿之间的分隔线来扩大草稿。
5. 移动外接鼠标、手机点 **收笔 / 换位置** 或电脑按 **Esc** 都会收笔。笔迹存入当前题目的草稿，可以撤销、清空、自动保存或继续作答。

配对码每次开启会话都会改变；关闭书写、切换题目或离开页面后，应重新开启并使用新码。旋转手机或断开连接会结束当前笔画，避免把不相连的笔画连起来。

## 黑屏操作的实际含义

TouchDeck 的 **黑屏盲操** 绘制纯黑画面，并降低本应用窗口的亮度，同时保持屏幕唤醒和触摸输入。因此它可以在看起来黑屏时书写，但**不是按电源键后的硬件息屏或系统锁屏手写**。实际锁屏时是否保留既有蓝牙连接，与持续接收手写触摸是两回事。

在手机书写界面的控制中心启用黑屏盲操。默认从屏幕顶部偏内的手势热区向下滑，可唤出控制中心；也可使用三指长按的备用手势。黑屏模式的热区用于菜单，不能作为笔迹输入。退出黑屏或离开操作界面后，应用恢复正常窗口亮度，不修改系统亮度设置。

本次已检查 Android 源码、APK 版本与签名，并验证电脑端配对、实际 WebSocket 笔迹传输和保存；实际手机的手写手感、无线网络及黑屏触摸仍需真机验收。TouchDeck 的普通蓝牙键鼠和单独 Wi-Fi 接收器属于其他使用方式，不是 MathMaster 手机草稿的必要条件。

## 网络与排查

MathMaster 的题库 API 仍运行在电脑本机 `127.0.0.1:8765`；手机书写使用独立 TCP **8766** 的 `/ink` 通道，传输配对和笔迹，不开放题库 API。Windows 网络提示中仅允许可信专用网络；不要把 8766 转发到公网。

无法连接时，核对 Wi-Fi 网段、电脑 IP、当前配对码、8766 端口和专用网络防火墙规则。校园/公司 Wi-Fi 的客户端隔离，以及 VPN、代理虚拟网卡可能妨碍直连。选实际 WLAN 的 IP，而不是 `127.0.0.1` 或代理地址。退出旧书写会话，再重开生成新码。

局域网通道使用明文 WebSocket，适合自己的可信网络。连接不需要云账号、付费 API 或任何常驻远程服务。
