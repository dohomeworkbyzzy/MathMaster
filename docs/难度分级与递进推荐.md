# 难度分级与递进推荐

题目相关性与难度分开处理。推荐先选同知识方向的候选题，再按训练档位筛选。不会因为没有合适的进阶题，就自动改推基础题。

## 难度与计算量

思维难度为入门、基础、标准、进阶、综合五档。评估依据包括方法是否直接、关键判断、隐藏条件、分类讨论、知识点综合和构造要求。计算量另记少、中、多；委托 AI 展开、求导或解方程，不等同于需要概念提示。

评级由模型结合题干、现有预解析、方法摘要和参考信息估计，带依据与可信度，不是实测考试难度。未校对题干、缺失图形信息、低可信度和未评级题不能用于自动升降档。用户可做个人校正，不影响其他用户。

新预解析会保存难度。旧预解析保持可用，在请求推荐时为当前题与相关候选按需补评，每次最多 16 道；可以重复请求继续补评。当前题也可单独评估或重新评估。评级按题干、题图、参考答案与分值版本匹配，修改后旧评级失效。

## 递进规则

- 同知识点、当前训练档位，连续三道不同题目独立通过：提高一档。
- 需要关键提示、看过答案或结论未独立核验：保持档位，清零连续通过计数。
- 连续两道不同题出现错误判断：降低一档巩固，保留原进阶目标。通过三道巩固题后再提高一档。
- 同一题同一版本重复练习只计一次；不同档位或难度待确认的练习不用于升级，并打断连续计数。
- “已完成”标记不作为独立掌握证据。自动升级要求真实 AI 会话中已有用户正确判断，并且本题结论经独立核验；旧记录不追溯猜测。
- 用户明确选择“简单一点 / 保持难度 / 挑战一下”时，以当前题为基准调整一档，并保存为该知识点的训练档位。默认“自动递进”沿用这个档位。

训练证据、档位、个人校正与推荐历史均按用户隔离。最近练过或推荐过的题会排除。候选池扩大至最多 60 道相关题，已评级题在整个候选池中参与筛选；未完成题和错题优先规则仍保留。

## 页面使用

网页与手机网页的 AI 解题页面都有“难度与下一题”。可查看本题评级、计算量、可信度，进行个人校正，然后选训练模式并推荐。推荐先显示难度变化和理由，点击“开始推荐题”才跳转；缺题时保留当前题并说明缺口。

难度初值来自模型估计，自动升降规则固定，不会根据少量作答把题目本身改成所谓真实难度。后续有足够数据后再考虑统计校准。

## 部署

本次增加后端接口和数据库表，需要更新完整服务器程序，不能只覆盖前端。

使用 `master-difficulty-update.exe` 选择现有含 `master.exe` 的服务器目录，执行更新。更新器保留数据、用户、API 设置并备份原运行文件；新表在启动时创建，旧题库和旧解析保留。完成后刷新浏览器。

开发构建使用 Windows Python 执行 `scripts/build_server_update.py --runtime artifacts/difficulty-build/master --output-name master-difficulty-update`。触摸板助手 ZIP 应在前端构建前生成，方法见触摸板助手文档。
